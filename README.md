# Nishant Patel — Portfolio

Personal portfolio of Nishant Patel, Full Stack Developer (MERN, Laravel, Shopify), built with **React 18 + Vite**.

## Getting started

Node.js 18+ required. This repo uses **pnpm**.

```bash
pnpm install
pnpm dev    # http://localhost:5173
```

## Build

```bash
pnpm build
pnpm preview
```

Deploy `dist/` to Vercel, Netlify, or any static host.

## Content

All content lives in `src/data.js` — projects, skills, experience, links.
